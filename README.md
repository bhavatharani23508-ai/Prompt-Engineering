
# Prompt Comparison Lab

## Overview

Prompt Comparison Lab is an interactive web application developed using Python and Streamlit to explore how different prompt engineering techniques influence responses generated by Large Language Models (LLMs).

The application allows users to submit a task, select prompting techniques, compare AI-generated responses, evaluate output quality, and download experiment reports. It provides a practical environment for understanding and evaluating prompt engineering strategies.

## Key Features

- **Interactive Dashboard:** A modern interface with customizable light and dark themes.
- **Multiple Prompting Techniques:** Implementations of six prompting approaches.
- **AI Response Generation:** Integration with the Groq API.
- **Prompt Inspection:** View the prompts used to generate responses.
- **Response Evaluation:** Rate responses based on clarity, relevance, and output format.
- **Evaluation Summary:** Calculate average scores and identify the highest-rated technique.
- **Report Export:** Download experiment results in Markdown format.
- **Navigation:** Separate pages for the dashboard, prompt workspace, and project information.

## Prompting Techniques

| Technique | Description |
|---|---|
| Zero-shot Prompting | Generates a response without providing examples. |
| One-shot Prompting | Uses one example to guide the model. |
| Few-shot Prompting | Uses multiple examples to guide the model. |
| Chain-of-Thought (CoT) | Requests a concise explanation of key steps. |
| Manual Chain-of-Thought | Provides an explicit sequence of steps for the task. |
| Tree-of-Thought (ToT) | Encourages comparison of multiple possible approaches. |

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/prompt-comparison-lab.git
cd prompt-comparison-lab
```

Replace `YOUR_USERNAME` with your GitHub username and use your actual repository URL.

### 2. Create a Virtual Environment

On Windows, run:

```powershell
python -m venv venv
```

Activate the environment:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

```powershell
pip install -r requirements.txt
```

### 4. Configure the API Key

Create a `.env` file in the project root directory:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Obtain an API key from the [Groq Console](https://console.groq.com/keys) and replace the placeholder with your own key.

Ensure that the model configured in `llm.py` is available to your Groq account.

### 5. Run the Application

Execute the following command:

```powershell
streamlit run app.py
```

The application will open in your default browser. The local address is usually:

```text
http://localhost:8501
```

## Response Evaluation

The application uses three criteria to evaluate generated responses. Each criterion is rated on a scale of 1 to 5.

| Criterion | Description |
|---|---|
| Clarity | Evaluates how understandable the response is. |
| Relevance | Evaluates how closely the response addresses the task. |
| Output Format | Evaluates whether the response follows the requested format. |

The average score is calculated using the following formula:

**Average Score = (Clarity + Relevance + Output Format) / 3**

The application identifies the technique with the highest average user-assigned rating. The result reflects the ratings provided by the user and should not be interpreted as an objective benchmark of model performance.

## Security and Configuration

API credentials must be kept private.

- Do not commit `.env` to GitHub.
- Do not include API keys in source code.
- Use `.env.example` to document required environment variables.
- Exclude virtual environments and Python cache files from version control.

Recommended `.gitignore` entries:

```gitignore
.env
venv/
__pycache__/
*.pyc
.streamlit/secrets.toml
```

Example `.env.example`:

```env
GROQ_API_KEY=your_groq_api_key_here
```
